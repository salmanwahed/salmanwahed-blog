Securing a New VPS: The Initial Steps After Purchase and the Best Practices

09 Aug 2023·4 min read
devops system-administration
cover image

After acquiring a VPS from any provider, we typically gain shell access to the root user. At this point, our first steps should include installing essential libraries and implementing basic security measures before proceeding with any deployment tasks. These tasks are also relevant for other freshly installed servers.

Update and Upgrade Packages

SSH into the server and update the package lists, then upgrade the installed packages to their latest versions.

sudo apt update
sudo apt upgrade

Install Essential Packages

These packages are often necessary for day-to-day server management and administration.

sudo apt install curl wget vim net-tools git

Secure SSH Login

To enhance security it's good practice to disallow root login and configure public-key authentication, disabling password-based login entirely. First, create a non-root user:

sudo adduser <username>
sudo usermod -aG sudo <username>

Open /etc/ssh/sshd_config, set PermitRootLogin to no, and restart the service once your key is in place.

Firewall Configuration

Ubuntu ships with ufw. Enable it and allow only the connections you need.

sudo ufw allow ssh
sudo ufw allow http
sudo ufw allow https
sudo ufw enable

Our basic setup is finished. From here you can go further — installing fail2ban and enabling automatic security updates are great next steps.
